Pi Network API Integration & Compliance

PiNova Global Hub · Last updated: 15 November 2026

Third-party application notice: PiNova Global Hub is an independent application. It is not Pi Network, is not operated by the Pi Core Team, and does not claim Pi Network endorsement, certification or sponsorship.

1. Purpose of this page

This page explains, at a high level, how PiNova intends to interact with Pi Platform services and the safeguards and limitations users should understand. It is an informational disclosure, not a claim that Pi Network has audited or approved PiNova.

2. Official Pi Platform integration

Where Pi features are enabled, PiNova integrates through the Pi SDK and supported Pi Platform APIs. Users should access Pi features through the official Pi application and follow the authorization prompts presented by Pi. Available functions depend on the app environment, granted permissions, Pi Platform availability and the current integration status.

Authentication and payment-related operations are subject to the official Pi Platform requirements. A client-side screen or message alone should not be treated as proof that a payment has completed. Users should rely on the applicable platform confirmation and transaction verification process.

3. Permissions and user control

PiNova requests only the Pi permissions needed for a feature when that feature is used. Users should review the permissions displayed by Pi before authorizing access. Authorization may be withdrawn through the controls made available by Pi. If a permission is not granted, or the Pi Browser bridge does not respond, the related feature may be unavailable.

4. Non-custodial security position

PiNova does not ask users to disclose Pi wallet private keys, wallet passphrases or recovery phrases. Never enter those secrets into PiNova, a vendor form, a support chat or any website claiming to represent PiNova. PiNova does not provide custodial wallet services.

5. Sandbox and Testnet

When the application is explicitly identified as Sandbox or Testnet, it is a testing environment. Test balances and test transactions are not real Pi and have no guaranteed monetary value. Sandbox behavior may differ from the production Pi environment. Do not use test transactions as evidence of a real-world payment.

6. Data handling

Pi-related account information and other information you choose to provide are handled as described in our Privacy Policy. PiNova does not sell personal information. Do not submit sensitive identity documents unless the relevant verification flow is available, clearly identifies the purpose and provides the required security information.

7. Platform rules and external resources

Use of Pi Network products and services remains subject to Pi Network's own terms, developer requirements and policies. Refer to the official Pi Developer Portal for current developer documentation and requirements. If this page conflicts with official Pi Network requirements, the official requirements govern use of Pi Platform services.

8. Availability and reporting concerns

Pi SDK authentication, permissions, APIs and network services may be unavailable or change without notice. PiNova may disable a related feature while investigating a technical or security issue. To report a suspected Pi integration or security concern, contact support@iddsnn.com. Do not include wallet secrets or unnecessary identity documents in support messages.

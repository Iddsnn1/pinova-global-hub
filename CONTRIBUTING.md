# Contributing to PiNova Global Hub

We welcome contributions from the Pi Network ecosystem developer community!

---

## Guidelines
1. Fork repository and create feature branches.
2. Adhere strictly to the modular architecture under `/src/modules/`.
3. Verify that all changes build cleanly using `npm run lint` and `npm run build`.
4. Do not commit actual API keys or secrets.
5. Ensure compliance with Pi Platform SDK v2 standards and PSTP security policies.
